no calls" to close the possibility of class change between caller/callee gates.
The primary catalog already correctly names
`Movement_UpdateSteeringTowardTarget`, **963 bytes**. No primary index regression
or catalog repair is alleged.

Original metadata divides it into eight contiguous ranges:
40,27,397,45,93,144,47,170 bytes, summing963. The first is

with the first runtime-function row suggests a fragment-as-function mistake,
