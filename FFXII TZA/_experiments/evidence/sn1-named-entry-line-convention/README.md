# Original debug source statements support one-based lookup

Method A. Original extracted files and existing admitted layout/source parser,
not original-code execution, compilation, simulation of gameplay or live FF12.
Run `python capture.py`: with retained raw present its actual default invokes
the read-only reducer; it does not reread/capture the source installation.
`check.py --fault-zero-based-mapping` and `--fault-ignore-shared-tail` must fail.
See raw.json for twelve exact identities, retained full inputs/parser/layout/
consumer preimages; result.json for exact operations/coordinates/controls.

The named-entry shortcut alone is insufficient. None of16 q0 coordinates
selects the label declaration under either candidate convention. Fourteen are
otherwise directory/q1-bound; two evctrl1 candidates remain UNACCEPTED because
q1 count160 versus jump count158, an already known shared-tail exception. Their
physical bytes are preserved but their attribution is not semantic evidence.

Original operation/literal pairs match one-based source lookup and reject the
zero-based lookup in these statements. The included-source transition and
consecutive0/1 and2/3 literals are stronger than proximity to a named label.
Source variable spelling and physical descriptor operands are retained;
descriptor-to-variable name identity is not newly proved by this package.
Each original match is a positive control. Actual private four-byte q0 records
with line+1, and original bytecode data with immediate+1, independently reject
the match. They are static byte interpretations, never executed instructions.
