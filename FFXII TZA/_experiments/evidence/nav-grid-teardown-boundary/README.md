# Navigation teardown routes the current block to release, then clears image state

Player view: this teardown function sends the current navigation-grid block to the engine's release entry when its pointer is nonzero, then requests a reset of navigation parameters and a larger adjacent image range. That gives us an explicit cleanup route. It does not prove the game calls it before every rebuild or that an actual memory block was freed in this research.
