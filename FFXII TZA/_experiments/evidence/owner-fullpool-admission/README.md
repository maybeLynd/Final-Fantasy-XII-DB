## Established source boundary

Owner submit3DDA70 stages a stack descriptor containing size, owner data32,
completion3DD850 and null cancellation. It calls32E620 at3DDAB9. Only after
the requester normally returns does3DDABE write3 to the retained owner+4.
No owner-state re-read/reconciliation guards that sole postcall state store.

Both nonnegative requester arms call32E870. If its free-head read is nonzero,
the local service loop is skipped. If zero,32E8AA calls32E070, followed by
service46DFE0 and35EA30; the loop repeats until free-head is nonzero. That
pump call dominates allocation/insertion32E8C9 and later descriptor consumption
on normal return in the zero partition. No deadline or eventual return is proved.

Queue service is therefore not universally deferred until owner submission
returns. A pump call does not establish an actual delivered callback. Delivery
requires the head/state/IO conditions in earlier queue evidence, which is reused
at its prior scope rather than rerun or treated as new native evidence.

IF serviced code changes this owner's state while the requester is active and
normally returns, the owner submitter subsequently writes3. This conditional
effect does not establish natural same-group primary reset, concurrent duplicate
request, stable resource destination, or safety/unsafety of a shipped load.
The descriptor is staged before service; resource-derived destination/length
lifetime across a real callback remains a separate requirement.
