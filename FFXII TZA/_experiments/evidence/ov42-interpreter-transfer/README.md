For an available queue word `w` (excluding `00CF` and `FFFF`), `e=w−00D0`. The decoder compares the DWORD with −1, then otherwise adds D0 in BX and uses its low 16 bits. Both u16 and s16 reads preserve that invariant over the available queue-word domain: s16 can become −1 only at low16=FFFF, which corresponds to the already-unavailable word CF; u16 never returns signed DWORD −1.
