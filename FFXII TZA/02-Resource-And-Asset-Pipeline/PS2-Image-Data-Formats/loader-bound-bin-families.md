## 1. The two request channels

| kind | request | complete | shape |
|---|---|---|---|
| `7` | `00249180` / `00249180`/`0024AB90`, `0032E620` with a callback | async file object → `obj+8` = blob base |
| `9` | `0032E400` | `0032E620` with a callback | async **named** object — `0036A190`/`0036C660` register a name (`"PCSkill"`) |

Every loader is **lazy**: it runs once when its feature first needs the file, stores the bound
result in a fixed `.data` slot, and a null check makes it idempotent (`texpack`'s
~~`cmp qword [*(0209AC30)+0x3D8], 0`~~ `cmp qword [0208EA88], 0`, `fontpack_it`'s `cmp qword [02AEE868], 0`).
*(Corrected 2026-09-29, OPUS, pass 1, `CON-164`: `002467A0` tests and fills `0208EA88`, its `7/0xD6` request. `[*(0209AC30)+0x3D8]`
is the tex2pack blob, tested and read by the tex2pack binder `00280670`.)*

The completion callback is where the format gets read: it receives the loaded blob and
**converts self-relative offsets to absolute pointers** (`offset + blob`), binding each into a
resource slot. Nothing bounds-checks the directory — the table is trusted.

## 2. The shared pack directory — `*pack_ys`, `fontpack_*`

All six `PackFiles\` families share one container:

```
+0x00   u32[dir_size/4]   self-relative offsets to packed sub-files
                          unused slots = 0xFFFFFFFF sentinel fill
        dir_size          = first used offset: 0x40 (16 slots) or 0x80 (32 slots)
sub-files                 standard formats: TIM2, MRP\0, CLT2, or raw font tables
```

The directory is **fixed-width and sentinel-filled**, not counted — the binder hard-codes how
many entries it walks, and the authored file pads the rest with `0xFFFFFFFF`.
