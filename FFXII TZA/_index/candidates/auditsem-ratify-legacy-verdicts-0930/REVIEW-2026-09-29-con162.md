## Byte verification

- `0043135A mov edi,r8d` / `0043135F test r8d,r8d` / `00431362 je 004313E9` — b is
  tested **before** the operator decode (`movzx word[rcx+0x0E]` at `00431368`).
- Zero-b arm `004313E9`: decodes the op from the same u16 (`shr 4; and 0xF`),
  `sub ecx,4; je ret a` (op 4 → `00431401 mov eax,ebx`), `cmp ecx,1; jne ret a`
  (ops 0-3 → return a), and for op 5 `sub edi,ebx` (0−a) / `jne 00431390` →
  `call f` returning `f(−a)+a`; a==0 falls through to `mov eax,ebx`. So ops 0-4
  return `a` with **no f call**; op 5 draws only when `a != 0`. Byte-exact.
- Op-3 arm `004313BA lea ecx,[r8+r8]` — bound is `2b`; among b≠0 it wraps to 0
  only at `b=0x80000000`. I4's scoping ("f(0) from this evaluator only via op 3
  with `b=0x80000000`") is exact.
- `+0x0E` operator is a loaded **u16** — sixteen record bytes read (A7 census
  shows loads covering 0x00..0x0F); "fifteen decide" is the honest qualification.

## The named attack

**"Can a caller reach `00431350` with b == 0 other than through `004314E0`?"**
Entrant census: exactly seven edges — `004314E0`'s tail `jmp` at `0043156E` and
**six direct calls from `0042FDB0`** (`0042FE75/FEF2/FF33/FF4F/FF73/FF98`).
Zero lea, imm, or data-pointer carriers — no indirect entry exists.
`0042FDB0` feeds `r8d` from runtime values: `[rax+4]` after `call 0020E600`,
`eax` from `call 00431080`, and `edi` on the `byte[rbx+0x2D]==0` arm — **nothing
clamps b to non-zero, so b==0 reaches `00431350` directly.**

**"Does any of those callers depend on a draw for b == 0?"** No: the sites
consume only the return value (`mov [rbp-0x24],eax` / store-and-return). A "draw"
is an RNG-ordering and scratch-bank side effect — `0042FDB0` reads neither the
LCG cell nor the VU0 scratch after the calls. The old unconditional table would
have predicted an LCG step that does not happen on this path; the corrected I2
(b==0 → ops 0-4 return a, op 5 conditional) matches the native code, so callers
on the zero-b path now read true semantics rather than a phantom draw.

## Verdict

**ACCEPT.** Correction is byte-exact and the draw-column narrowing survives the
direct-entrant attack: b==0 is real and reachable outside the wrapper, and the
corrected semantics are the ones callers actually observe.
