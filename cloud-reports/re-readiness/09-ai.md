## 1. Interface

The system has two halves that never call each other:

- **Action selection.** A per-frame driver and a pending-selection queue call one selector. The selector tries four
  order sets in a fixed order. Each attempt is the **gambit walk**: try a subgroup's records in order, evaluate each
  one's condition and target, and commit the first that matches.
- **Enmity.** A per-foe threat vector. Landed actions raise it, propagation spreads it and redistribution moves it.
  A periodic decay drains it, and the selector's condition language reads it.

The configuration layer (three gambit banks per party member, rebuilt into runtime order sets) feeds the first half.

### 1.4 Order (what runs when in a frame, and what triggers it)

The pages give this chain (`gambit-evaluation-and-enmity.md:375-402`):

```
field frame → lifecycle frame 00233F70, once per unit
  → BattleUnit_RunPeriodicCombatMaintenance 00310DB0 → BattleEnmity_UpdatePeriodicDecay 00321530
      (early exits: no stats record, special-sequence presentation 022C2160 = 5/6, field bit-15 permission,
       unit outside the active lifecycle branch)                    gambit-evaluation-and-enmity.md:474-480
  → BattleUnit_UpdateCombatFrame 00308610
      order current → 00305AB0(unit, 1)  (resume walk)
      no order      → flag 0x20, enqueue id
BattleUnit_ProcessPendingActionSelectionQueue 00313CD0 → 00305AB0(unit, 0)   (≤ 8 per call)
00305AB0: player command → else A(+0x6E8, sg 0) → B(+0x6F8, sg 0) | on B fail: clear B, go to D
          → C(+0x6E0, sg +0x6B5) only when B was not eligible → D(+0x6F0, sg 0) → 0x4021 if resume_mode == 0
          which-gambit-set-fires-and-how-a-command-switches-it.md:58-103
walk (per record): resume tests → 003014C0 → 0030F760(…, cancelFirst = 1) → [third call 004697C0 on resume]
an action lands → 003216E0 → 00321850, 003219D0, 00321B00 (in that order)     CONTRACT-enmity.md:89-93
```

What the pages leave open about order:

- **Position of `00313CD0` in the frame: not stated.** The pages say only "up to 8 queued units per call"
  (`gambit-evaluation-and-enmity.md:380`).
- **Order between the decay and the combat frame inside `00233F70`: not stated.** The crossings list both callees
  (`gambit-evaluation-and-enmity.md:1993`; `which-gambit-set-fires-and-how-a-command-switches-it.md:572`) but not
  their order.
