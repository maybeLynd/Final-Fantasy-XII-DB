## How to read the citations

Citations are `ALIAS:line` or `ALIAS:a-b`, with the **current** line numbers. The aliases are pass 1's (one alias,
one page, path relative to `FFXII TZA/00-Engine-Core-Runtime/`), plus `REG` for the register. Pass 1's line
numbers are stale, because most pages grew; the table gives both lengths. Pages outside this folder have no alias.
They are cited as a plain path from `FFXII TZA/` with a line number and **without** a quotation. They were read
only to settle a DOC verdict (the answer exists there, and the 00 page lacks the pointer).

**Quote check.** A script compared every quoted span that carries an alias citation (566 of them) with the cited
lines of the current snapshot. All 566 matched (whitespace normalised; `…` marks an elision, and each piece was
matched).

**Verdicts** (per the brief): **CLOSED** (now stated; quoted), **NARROWED** (partly stated; the rest is named),
**OPEN** (still missing; the current line is re-cited), **WRONG-IN-PASS-1** (the information was already there
on 2026-10-02, or the gap misread a page). **Classes** for OPEN, NARROWED and new gaps: **STATIC** (a desk read of
the executable or data), **RUNTIME** (needs a live observation), **DATA** (needs a census of shipped game data),
**DOC** (the answer exists on another page; the 00 page lacks the pointer). "Evidence-only" marks a gap that pass 1
listed but that does not block a port (a declared limit of a proof).

**Scope.** Pass 1's §2 (176 self-stated gaps G-1..G-176, 102 structural gaps S-1..S-102) is re-decided in full
here. Pass 1's §3 (545 contradictions) was **not** re-adjudicated. Where a reader found that a current page
settles one of them, the row says so. A new disagreement between pages is listed as a new gap only if pass 1's §3
does not already carry it.
